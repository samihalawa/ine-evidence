## Listing and runtime

Encuentra series del INE y presenta sus cifras con periodo, unidad, definición y límites de comparación.

Audience: Analistas, periodistas, docentes y consultoras.

One declared local stdio MCP process provides the scoped adapters, historical demo and deterministic report text. Python 3.11+ is required; there are no third-party runtime dependencies, account credentials, hidden hooks, shell launchers or remote executables. No publisher-hosted MCP endpoint is claimed.

## Reviewer walkthrough

Install the exact candidate marketplace and verify the declared server appears. Call `ine_evidence_demo` and inspect its dated historical marker. Call `ine_evidence_report` with the demo operation and `format: html`; it returns escaped portable text, with no file write or external assets. Exercise the domain operation `ine_series_change` only with an authorized official-source query and inspect dates, coverage, provenance and partial errors.
